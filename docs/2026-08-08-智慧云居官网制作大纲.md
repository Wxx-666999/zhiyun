# 「智慧云居」官网制作大纲

- 日期：2026-08-08
- 状态：草稿待审
- 关联项目：智寓云居（Django 6.1 后端 + Vue 3 前端，见 `docs/superpowers/specs/2026-08-08-vue-frontend-design.md`）

## 0. 一句话目标

做一套「类涂鸦智慧租住官网」的 B2B 行业解决方案官网：让公寓运营方、房东、学校园区、合作伙伴在 3 分钟内看懂产品价值并产生咨询/试用意向；同时为租客端提供信任背书与下载入口。

## 2. 定位与目标人群

- 网站类型：品牌官网 + 产品营销站 + 线索获取（lead-gen）
- 受众 A（核心）：公寓/房东/学校园区运营方，决策者
- 受众 B：租客（体验产品、下载小程序/App）
- 受众 C：服务商 / 硬件厂家（生态合作）
- 成功指标：留资量、试用申请量、小程序下载量、咨询转化率

## 4. 页面清单与每页结构（线框级）

### 4.1 首页
1. 顶部导航：LOGO | 产品▾ | 方案▾ | 场景体验 | 案例 | 定价 | 合作 | 免费试用 / 联系我们
2. Hero：主标题「智慧云居 · 智能公寓云管理平台」+ 副标题 + 双 CTA（免费试用 / 预约演示）+ 背景（公寓实景或 3D 渲染 + 产品界面浮层）
3. 信任数据条：如「10 万+ 在线设备 / 100+ 合作项目 / 99.9% 服务可用」（占位，待真实数据）
4. 场景 Tab：长租公寓 / 政策性租赁住房 / 学校园区 → 每 Tab 4 个功能点 + 了解更多
5. 核心能力：SaaS 管理 / 移动端平台 / 硬件生态 三卡片
6. 为什么选择我们：四宫格（降本增效 / 安全省心 / 场景互联 / 开放生态）
7. 产品界面展示：真实后台截图轮播或短视频
8. 适用客户：三角色卡（运营方 / 合作服务商 / 硬件厂家）
9. 合作客户 LOGO 墙
10. 底部 CTA 横幅（免费试用）
11. 页脚：产品 / 公司 / 帮助 / 语言 + 备案

### 4.2 产品页
- 租住 SaaS：租务管理（房源/合同/账单/催收）、设备管理、通行权限、数据报表、租客小程序
- 租住 PaaS：开放 API、设备接入 SDK、数据接口、三方系统（PMS）对接
- 硬件生态：智能门锁 / 门禁 / 水电表 / 摄像头 / 网关 产品图 + 参数

### 4.3 解决方案页（每类场景同一模板）
痛点 → 方案架构图 → 功能点 → 效果数据 → 案例 → CTA

### 4.4 场景体验页
后台演示视频 / 截图画廊 / 可点击原型入口

### 4.5 客户案例页
客户 LOGO + 项目背景 + 方案 + 效果数据（人房比、能耗、收缴率）+ 决策人引语

### 4.6 定价页
版本卡（基础版/专业版/旗舰版）+ 免费试用 + 计费 FAQ

### 4.7 合作页
服务商 / 硬件厂商两类合作入口 + 合作流程四步

### 4.8 租客端页
小程序/App 功能展示（开门、缴费、报修、场景联动）+ 下载二维码

## 5. 视觉设计规范

- 配色：主色科技蓝（如 #005CFF 家族）+ 辅助青色/橙色点缀；背景白 + 浅灰分区；深色区块用于数据/CTA 区
- 字体：中文优先「思源黑体 / 阿里巴巴普惠体」或系统字体栈；标题加粗大字号、正文 14–16px
- 组件：圆角卡片（8–12px）、轻阴影、蓝色主按钮、线框图标
- 图片风格：现代公寓实景/3D 渲染图 + 产品 UI 截图（比插画更可信）
- 动效：滚动渐入、Tab 切换、数字滚动，克制使用

## 6. 技术方案（结合现有架构）

方案 A（推荐）：官网并入现有 Vue 3 前端工程
- `frontend/` 新增营销路由（`/`、`/product`、`/solutions`…），与后续管理端 SPA 共存或采用子路径
- 静态内容为主；表单（免费试用/联系）提交到 Django 新增 API（如 `POST /api/leads/`）
- 复用 Vite + Vue Router 4 + Pinia，联调代理 `/api` → Django 8000

方案 B：独立轻量静态站（VitePress/Nuxt）托管 CDN，仅表单调 API
- 更轻、SEO 友好，但与现有工程分离、需单独维护

方案 C：先做单页落地页，验证转化后再扩展多页
- 最快上线 MVP，适合首版

建议：先按「方案 C + A」组合——在 Vue 3 工程内先做一页式落地页 MVP，跑通表单入库后，再扩展多页。

## 7. 内容与素材清单（需准备）

- 文案：品牌 Slogan、各页标题/副标题/功能描述、FAQ 20 条
- 图片：公寓实景图 8–10 张、3D 渲染图、产品后台截图 6–8 张、硬件产品图
- 数据：项目数 / 设备数 / 人房比提升 / 能耗下降等可公开数据
- 案例：2–3 个客户案例素材
- 视频：1 分钟产品演示视频（可选）
- 合规：ICP 备案号、隐私政策、用户协议

## 8. 开发里程碑（建议排期）

| 阶段 | 内容 | 周期 |
|---|---|---|
| M1 | 单页落地页（Hero + 场景 + 价值 + CTA + 表单） | 约 1 周 |
| M2 | 产品页 / 解决方案页（路由 + 内容） | 1–2 周 |
| M3 | 案例 / 定价 / 合作页 | 约 1 周 |
| M4 | 联调上线（表单入库、SEO、埋点、响应式） | 0.5–1 周 |
| M5 | 迭代（SEO 内容、租客端下载页、多语言） | 持续 |

## 9. 验收标准

- 桌面 / 移动端响应式正常
- 表单提交成功且 Django 入库（`/api/leads/`）
- 页面首屏加载 < 2s，核心 CTA 可点击
- 埋点可统计留资 / 试用转化
